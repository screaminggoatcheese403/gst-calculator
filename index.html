How to use GST Split

Tap Before GST if you know the price, or Total paid if you know the amount charged. Use the calculator keys to enter the number.

  1. Tap Tip to enter a separate tip. It is not subject to GST.
  2. The first 2.5% is the QuickBooks NPR 2.5% tax amount. The other portion is an Exempt expense line.
  3. Match QBO is recommended. The ↑ and ↓ options manually change which portion receives the extra cent.
  4. Tap QuickBooks lines to see the entry, or Copy entry to copy it.

Add to iPhone Home Screen

Once this calculator is published to an HTTPS website (such as GitHub Pages), you can install it like an app.

  1. Open the calculator's website in Safari on your iPhone.
  2. Tap the Share icon (square with upward arrow).
  3. Choose Add to Home Screen, then tap Add.
  4. Open GST Split from the new icon. It works offline after it has been loaded once.

Opening an HTML file directly from Files is useful for testing, but not a reliable way to install an offline web app. Use the GitHub Pages version.
